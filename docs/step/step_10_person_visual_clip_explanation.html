EgoCom Masked Person CLIP Features

This preprocessing step extracts visual CLIP features for each mapped person track. It uses the final person mapping to union one or more refined-mask segment ids, blacks out the rest of the full frame, and feeds the masked image to CLIP ViT-L/14. If a frame has no mapped segment for that person, the extractor feeds a full black image so the feature sequence remains aligned to every frame in the chunk.

Inputs And Outputs

RolePathUse
Person mapping val/person_face_mapping/*/remap_all_chunks.json Maps final person ids to refined-mask segment ids for each clip.
Refined masks val/refined_mask/<video>/mask.pt Stores frame-indexed masks keyed by local segment id.
Frames val/frame/<video>/frame_XXXXXX.jpg Provides original RGB pixels. Mask index 0 aligns to frame_000001.jpg.
Feature output val/person_visual_clip_features/<scene>/person_<id>/<video>.pt Stores normalized CLIP features and per-frame metadata.
Visualization output val/person_visual_clip_features/<scene>/person_<id>/visualizations/*.jpg Stores sampled full-frame masked images inside each person's folder.

Pipeline

CLIP Payload

Each output .pt file stores features, zero-based frame_indices, frame_stems, segment_ids, per-frame mask_bboxes, mask_pixel_counts, and source paths. Features are L2 normalized and saved as float32.

features.shape == (num_source_frames, 768)

image_mode == "full_frame_masked_black_background_else_black_frame"

has_masks and frame_statuses identify black fallback rows.
