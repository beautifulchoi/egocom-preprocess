EgoCom Mask-Pooled CLIP And DA3 Features

This document describes the two frame-aligned masked feature extractors: src/step_11_extract_person_masked_clip.py and src/step_12_extract_person_masked_da3.py. Both run the model on the full RGB frame, align the mapped person mask to the model's spatial feature grid, and average only the features covered by that mask.

This is different from src/step_10_extract_person_visual_clip.py, which blacks out non-person pixels before running CLIP and then saves CLIP's global image feature. The mask-pooled extractors preserve the original full-frame model input and apply the mask at the spatial feature level.

Masking Example

The mask is not multiplied into the RGB image for these two extractors. Instead, it is resized onto the model's spatial feature grid and used as a pooling weight.

CLIP Mask-Pooled Patch Token Features

src/step_11_extract_person_masked_clip.py runs Hugging Face CLIP vision on the full RGB frame with hidden states enabled. It selects the requested hidden state, drops the first CLS token, infers the square patch grid, and resizes the person mask to that grid with nearest-neighbor interpolation. 

M_t(x, y) = OR_{s in S_p} M_{t,s}(x, y)

H_t_l = CLIPVision_l(I_t)                  # shape: (1 + N, C)
P_t = H_t_l[1:]                            # remove CLS, shape: (N, C)
m_t = ResizeNearest(M_t, G, G).reshape(N)

z_t_clip = sum_i m_t[i] * P_t[i] / max(sum_i m_t[i], eps)
f_t_clip = z_t_clip / max(L2Norm(z_t_clip), eps_norm)

N = G * G. Empty or absent masks do not produce a pooled vector; the saved frame row is a zero vector so frame alignment is preserved. By default, pooled vectors are L2-normalized and saved as float32.

DA3 Mask-Pooled Feature Map Features

src/step_12_extract_person_masked_da3.py imports Depth Anything 3 from _external/depth-anything-3/src without editing the vendored source. It uses DA3's input processor and backbone export path to obtain an auxiliary feature map, then applies the same resize/crop geometry to the mask before resizing it to the feature map grid. 

M_t(x, y) = OR_{s in S_p} M_{t,s}(x, y)

A_t_l = DA3AuxFeature_l(I_t)               # shape: (H_f, W_f, C)
M_t_prime = DA3InputGeometry(M_t)          # resize/crop/patch alignment
m_t = ResizeNearest(M_t_prime, H_f, W_f)

z_t_da3 = sum_{u,v} m_t[u,v] * A_t_l[u,v] / max(sum_{u,v} m_t[u,v], eps)
f_t_da3 = z_t_da3 / max(L2Norm(z_t_da3), eps_norm)

The current default DA3 configuration is model_id=depth-anything/DA3METRIC-LARGE, layer=23, process_res=504, process_res_method=upper_bound_resize, and patch_size=14. For the processed EgoCom frames this commonly yields a 27 x 36 feature grid with feature dimension 1024.
