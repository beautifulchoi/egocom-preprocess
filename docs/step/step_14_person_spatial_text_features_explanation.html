EgoCom Person Spatial Text Features

This preprocessing step converts mapped person masks into spatial language with InternVL2, then encodes that language with T5-XXL. The output stays frame-aligned with the source chunk by writing one text line and one feature vector per frame.

Pipeline

Inputs And Outputs

RolePathUse
Person mapping val/person_face_mapping/*/remap_all_chunks.json Maps final person ids to refined-mask segment ids for each chunk.
Refined masks val/refined_mask/<video>/mask.pt Provides frame-indexed person masks. Mask index 0 aligns to frame_000001.jpg.
Frames val/frame/<video>/frame_*.jpg Provides original RGB frames for the InternVL2 query image.
Text output val/person_spatial_internvl2_text/<scene>/person_<id>/<video>.txt Stores one InternVL2 response per frame, with null for absent or tiny masks.
Feature output val/person_spatial_t5_features/<scene>/person_<id>/<video>.pt Stores T5-XXL pooled text features with frame metadata.

Commands

InternVL2 dry run for one track: python /home/prj/egocom_preprocess/src/step_14_extract_person_internvl2_text.py --split val --limit 1 --dry_run --overwrite

InternVL2 extraction: python /home/prj/egocom_preprocess/src/step_14_extract_person_internvl2_text.py --split val --min_mask_pixels 100

T5-XXL feature extraction: python /home/prj/egocom_preprocess/src/step_15_extract_person_t5_text_features.py --split val

Null Rule

A frame is written as null when the mapped segment is absent, the frame cannot be read, the resized mask is empty, or the union mask has fewer than 100 pixels. T5-XXL encodes null as text, preserving a one-to-one relationship between frames, text lines, and feature vectors.
