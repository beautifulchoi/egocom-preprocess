Step 09 - Final Person Mask Extraction

src/step_09_extract_final_person_masks.py materializes the final per-person masks that are implied by the remapped face-to-segment chains. It runs after step_08_report_merged_segments.py and before the depth-lift, visual-CLIP, masked-pooling, and spatial-text feature steps.

Inputs

Input Purpose
{split}/person_face_mapping/{scene}/remap_all_chunks.json Maps each target person id to one or more refined segment ids for every view clip.
{split}/refined_mask/{view_clip}/mask.pt Stores frame-indexed refined person masks by segment id.
{split}/frame/{view_clip}/*.jpg Provides the canonical frame order, frame names, and output image shape.

Mask Mapping

For each view clip in each remapped chunk, the script reads the people block. A target person uses merged_segment_ids when available and falls back to primary_segment_id. All available segment masks for that person are unioned per frame. If no mapped segment appears in a frame, the script still writes an all-black mask so that the output sequence remains aligned one-to-one with the frame directory.

Outputs

{split}/final_mask/{scene_key}/chunk_XXXX/{view_clip}/person_{id}/{frame_name}.jpg
{split}/final_mask/{scene_key}/chunk_XXXX/{view_clip}/summary.json
{split}/final_mask/summary.json

The JPG masks are grayscale 8-bit images. Foreground person pixels are written as 255 and background pixels as 0. The filename is copied directly from the corresponding source frame, for example frame_000175.jpg.

Usage

python /home/prj/egocom_preprocess/src/step_09_extract_final_person_masks.py --split train
python /home/prj/egocom_preprocess/src/step_09_extract_final_person_masks.py --split all_existing --overwrite
python /home/prj/egocom_preprocess/src/step_09_extract_final_person_masks.py --split train --scene_key day_1__con_1__part1 --limit 1 --overwrite

Diagnostics

Each view-level summary.json records the mapped people, segment ids, source paths, frame count, nonempty-mask count, black-mask count, and unreadable-frame count. The split-level summary aggregates the same counters across all processed views.
