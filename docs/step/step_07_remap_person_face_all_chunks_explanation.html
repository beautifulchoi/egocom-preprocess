EgoCom All-Chunk Person Remapping

src/step_07_remap_person_face_all_chunks.py uses the selected conflict-free chunk's representative embeddings as fixed person prototypes, then remaps every chunk in the scene. It does not modify original mask files. If multiple disconnected segment ids indicate the same real person, it records them as a merged group. 

python /home/prj/egocom_preprocess/src/step_07_remap_person_face_all_chunks.py --split all_existing --save_vis --overwrite

Process

The remap pass records segment-id indications only; it never combines mask pixels.

Merge Rule

ConditionDefault
Minimum face embeddings per segment10
Candidate segment similarity>= 0.70
Candidate score gap from primary<= 0.10
Frame overlap with current group<= 5 frames
