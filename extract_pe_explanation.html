EgoCom Mask-Pooled Positional Encoding Features

extract_pe.py adds a frame-aligned positional encoding feature branch for mapped EgoCom person tracks. Instead of masking RGB pixels and extracting one global visual feature, it builds a ViT-style 2D positional table, resizes each target-person segmentation mask to the patch grid, and averages positional vectors over the mask-covered patch area.

Pipeline

Encoding Modes

Sinusoidal

The sinusoidal path uses Hugging Face MAE's get_2d_sincos_pos_embed(hidden_size, patches_per_side), multiplied by pe_scale. The resulting table is fixed and has shape (patches_per_side * patches_per_side, hidden_size).

RoPE

The RoPE path creates a standalone 2D rotary sin/cos coordinate table. Half of the channels encode the y coordinate and half encode the x coordinate. This produces the same output shape as sinusoidal PE, so both modes are interchangeable downstream.

hidden_size must be divisible by 4 because each spatial axis needs paired sine and cosine channels. The default feature shape is 16 x 16 patches and 768 channels.

Mask Pooling

For each mapped person and frame, all assigned segment masks are unioned. The union mask is resized from image resolution to the PE patch grid with area interpolation, preserving fractional coverage per patch. Pooling is a weighted average over the PE table: 

features = pe_grid.reshape(H * W, C)
mask = resized_mask.reshape(1, H * W)
pooled = mask @ features / (mask.sum(-1, keepdim=True) + 1e-6)

If the mapped segment is absent or the resized mask is empty, the extractor writes a zero vector and marks the frame status as absent_segment or empty_mask_after_resize. This keeps every output tensor aligned with the original chunk frame sequence.

Manifest Integration

build_egocom_window_manifest.py now requires the PE branch next to depth, CLIP, and T5. It discovers {split}/person_pe_features/{scene}/person_{id}/*.pt, merges chunks onto the same global 5 FPS timeline, writes windowed PE sidecars, and adds tgt_pe_feature_path, tgt_pe_num_valid_frames, and tgt_pe_valid_ratio to each manifest row.
