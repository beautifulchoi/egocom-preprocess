EgoCom Person Depth Lift

This preprocessing step converts each mapped person mask into a compact per-frame camera-space depth summary. It combines identity mapping, refined segmentation, saved face detections, DA3 metric depth, and DA3 intrinsics that were estimated on the resized DA3 depth grid.

Inputs And Outputs

RolePathUse
Person mapping train/person_face_mapping/*/remap_all_chunks.json Maps segment ids in each clip to actual person ids.
Refined masks train/refined_mask/<video>/mask.pt Provides frame-indexed segment masks at frame resolution.
Face bboxes train/person_face_emb/<video>/embeding.pt Stores per-segment valid frame indices and face bbox coordinates.
Depth train/da3/monocular/<video>/depth/frame_XXXXXX.npy Metric monocular depth on the DA3 resized grid.
Intrinsics train/da3/nested/<video>/camera_params/intrinsics.npy Camera intrinsics aligned to the DA3 depth grid.
Output train/person_depth_lift/<scene>/person_<id>/<video>.npz Per-frame lifted coordinates, bboxes, status labels, and diagnostics.

Pipeline

Lift Region

Frame Space

person mask face bbox lift pixels

Depth Space

The mask is resized with nearest-neighbor interpolation to preserve labels. Bbox coordinates are scaled by width and height ratios from frame space to depth space. The depth pixels selected by the region are back-projected using DA3 intrinsics from the same resized grid.

x = ((u - cx) / fx) * z

y = ((v - cy) / fy) * z

d = sqrt(x^2 + y^2 + z^2)
